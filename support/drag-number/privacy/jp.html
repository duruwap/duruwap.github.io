02アプリが取り扱う情報と目的

① 開発者が収集する情報：なし

本アプリには会員登録やログインはなく、開発者は氏名・メールアドレス・電話番号など、利用者を直接識別する情報を収集しません。スコア・プレイ回数・モード別ベストスコアなどのゲーム記録と、言語・サウンド・BGM の設定はお使いの端末にのみ保存され、開発者や外部サーバーに送信されることはありません。

② 本アプリに組み込まれた Google サービスが自動的に収集する情報

サービス取り扱う情報目的
Google AdMob広告識別子（IDFA・広告 ID）、IP アドレスに基づくおおよその位置、端末情報（機種・OS・言語）、広告の表示・クリック履歴広告の配信、広告効果の測定、不正クリックの防止、（同意した場合）パーソナライズ広告
Google Firebase Analyticsアプリインスタンス ID（分析 ID）、アプリ内の利用イベント、端末・OS・国の情報アプリ改善のための利用統計
Google Firebase Cloud Messaging通知配信用トークン（通知をオンにした場合のみ）お知らせ・イベント通知の配信

これらの情報は上記の目的以外には利用しません。目的が変わる場合は事前にお知らせし、必要に応じて同意を得ます。

03保存期間と破棄

情報保存期間破棄
端末に保存されたゲーム記録・設定利用者が削除するまで設定の「記録リセット」またはアプリの削除により直ちに削除

通知トークン通知をオフにするかアプリを削除するまで使用されなくなり、Google のポリシーに従って削除

開発者は、保存期間が経過した場合や取扱いの目的を達成した場合、遅滞なく情報を破棄します。電子ファイルは復元できない方法で削除し、紙媒体の個人情報は保有していません。

05第三者による行動情報の収集（パーソナライズ広告）

本アプリでは、Google LLC が AdMob を通じて広告識別子や広告の利用履歴などの行動情報を直接収集し、広告およびパーソナライズ広告の配信に利用することがあります。Google はこれらの情報を自社のプライバシーポリシー（https://policies.google.com/privacy）に従って取り扱います。開発者は、個人情報を Google に販売したり、対価を得て提供したりすることはありません。

パーソナライズ広告を拒否する方法

  • iOS：端末の設定 › プライバシーとセキュリティ › トラッキングで、本アプリのトラッキングをオフにします。
  • Android：端末の設定 › プライバシー › 広告（または Google › 広告）で、広告 ID を削除またはリセットします。
  • 欧州など同意が必要な地域：本アプリのメニューの広告のプライバシー設定で変更します。

拒否しても本アプリは引き続きご利用いただけます。その場合はパーソナライズされていない広告が表示されます。

07同意と選択

  • 欧州など同意が必要な地域では、初回起動時に同意画面が表示されます。メニューの「広告のプライバシー設定」からいつでも変更できます。
  • iOS では、最初のゲームが終わった後にトラッキングの許可を確認します。許可しなくても、これまでどおりご利用いただけます。
  • 通知はオンにした場合のみ届き、アプリの設定または端末の設定からいつでもオフにできます。
  • 同意が必要な地域では、同意を確認するまで利用統計を収集しません。

08利用者の権利と行使方法

利用者は、いつでもご自身の個人情報について閲覧・訂正・削除・取扱いの停止・同意の撤回を求めることができます。

  1. 本アプリの設定 › 分析 ID で ID をコピーします。
  2. 分析 ID とご要望を duruwap@naver.com までお送りください。
  3. 開発者は、ご要望を受け取ってから 10日以内に対応し、結果をお知らせします。期間内に対応できない場合は、その理由と対応予定日をお知らせします。
  • 端末に保存された記録は、設定の「記録リセット」またはアプリの削除により、ご自身で削除できます。
  • 広告関連の情報は第 05 条の方法で拒否できます。Google アカウントをお持ちの方は https://myadcenter.google.com でも管理できます。
  • 開発者は利用者を識別できる情報を保有していないため、分析 ID がなければ特定の利用者の統計データを見つけることができません。その場合でも、データは第 03 条の期間が経過すると自動的に削除されます。
  • 法定代理人または委任を受けた代理人を通じて権利を行使することもできます。

09安全管理措置

開発者は、個人情報を保護するために以下の措置を講じています。

  • 最小限の収集：会員登録やログインはなく、ゲーム記録はお使いの端末にのみ保存されます。
  • アクセス制御：Google・Firebase・AdMob の管理コンソールには開発者のみがアクセスでき、2段階認証を使用しています。
  • 通信の保護：Google サービスとの通信には暗号化された接続（HTTPS/TLS）を使用します。
  • 最小限の保存：統計データの保存期間は最短の設定（2か月）にしています。
